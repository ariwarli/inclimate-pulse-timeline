7 Fase Pembangunan Sistem // Rincian Lengkap

Bahasa Berbasis Tujuan, Aktivitas, dan Hasil Nyata

[FASE 01] 1–3 SEP 2026

Perencanaan & Desain

// FOKUS UTAMA:
  • Finalisasi kebutuhan sistem monitoring
  • Penyelarasan alur kerja kuesioner
  • Penentuan tampilan layar dashboard
  • Penyiapan fondasi pengembangan
// HASIL / OUTCOME:

Arah sistem dan desain dashboard siap digunakan sebagai dasar pembangunan.

[FASE 02] 4–9 SEP 2026

Persiapan Infrastruktur

// FOKUS UTAMA:
  • Menyiapkan domain resmi dan server aman
  • Menyiapkan lingkungan aplikasi siap pakai
  • Menyiapkan ruang penyimpanan data aman
  • Menyiapkan sistem pemrosesan pesan kapasitas tinggi
// HASIL / OUTCOME:

Fondasi teknologi siap digunakan oleh aplikasi secara stabil dan andal.

[FASE 03] 10–12 SEP 2026

Pembangunan Aplikasi Inti

// FOKUS UTAMA:
  • Membangun struktur inti aplikasi & alur logika
  • Menyiapkan pengelolaan pengguna & otentikasi
  • Menyiapkan pembagian peran & hak akses admin
  • Membangun kerangka dasar dashboard monitoring
// HASIL / OUTCOME:

Aplikasi inti dan dashboard dasar mulai dapat digunakan dan diakses.

[FASE 04] 13–17 SEP 2026

WhatsApp & Campaign

// FOKUS UTAMA:
  • Menghubungkan sistem dengan WhatsApp resmi
  • Menyiapkan penerimaan dan pengiriman pesan
  • Menyiapkan peserta monitoring & jadwal Pulse Check
  • Menyiapkan reminder otomatis & pelacakan status
// HASIL / OUTCOME:

Sistem dapat mengirim, menerima, dan menjadwalkan komunikasi monitoring peserta melalui WhatsApp.

[FASE 05] 18–22 SEP 2026

AI & Knowledge System

// FOKUS UTAMA:
  • Mengaktifkan AI untuk membaca respons peserta
  • Membuat AI memahami riwayat percakapan peserta
  • Menghubungkan AI dengan materi program IN-CLIMATE
  • Memproses pesan suara (voice note) menjadi data terstruktur
// HASIL / OUTCOME:

AI dapat membantu memahami respons peserta dan menghasilkan data monitoring yang lebih terstruktur.

[FASE 06] 23–25 SEP 2026

Dashboard, QC & Release

23 SEP: Dashboard Selesai

Daftar peserta, riwayat percakapan, grafik insight, pencarian & ekspor.

25 SEP: PRODUCTION RELEASE ★

Initial Live System aktif dan siap uji bersama TAF.

// HASIL / OUTCOME:

Sistem awal tersedia di production dan siap masuk tahap penggunaan serta evaluasi.

[FASE 07] 26 SEPTEMBER 2026 +

Stabilisasi & Persiapan UAT

// FOKUS UTAMA:
  • Memantau penggunaan awal sistem di lapangan
  • Memeriksa jika ada kendala respon pesan WhatsApp
  • Melakukan perbaikan kritis secara responsif
  • Menyiapkan daftar isu dan peningkatan bersama tim M&E
  • Menyiapkan tahap User Acceptance Testing (UAT) resmi
// TARGET AKHIR SIKLUS:

Sistem monitoring berjalan secara ajeg, akurasi pemrosesan AI terkalibrasi, dan para PIC program siap menjalankan pemantauan secara mandiri.

// HASIL / OUTCOME:

Sistem lebih stabil dan siap memasuki tahap UAT serta iterasi pengembangan berikutnya.
